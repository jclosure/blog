<p>Enterprise Library’s Logger is powerful and convenient.<span>  I</span>t&#8217;s default TextFormatter provides a suitable human readable format, and it also allows you to implement custom formatters to suite your needs.  I think that being able to work with log data without having to manually parse strings, can really simplify the development of tools for mining logs. <span>  </span>To this end, I whipped up <a href="http://cid-3fc3980d58cf7efb.skydrive.live.com/self.aspx/Public/LogChewer.WinFormSample.zip">a small WinForms app</a> that demonstrates how to take log entries originating from a text spool, convert them into objects, and query them with Linq.  The primary goal was to provide simple UI that enables log search, filter, and find, with sorting, grouping, etc. </p>
<p>First off, the heavy lifting in this sample is provided by the <a href="http://www.codeplex.com/entlibcontrib/SourceControl/ListDownloadableCommits.aspx">EntLib Contrib</a> LogParser.<span>  </span>Their FilteredLogReader class drives a tokenizer, which creates and populates LogEntry objects out of log text.   The tokenizer will use any formatting template, in our case, I’ve used the built in “Text Formatter”.<span>   </span>When it executes, it generates a RegularExpression capable of matching and trapping the values involved in populating our collection of LogEntry objects.<span>  </span>Ultimately, we are provided with a simple API for driving all of this.<span>  </span>Here’s a brief sample: <span style="color:blue;font-size:10pt;"></span></p>
