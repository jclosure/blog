<p>Wikipedia defines a quine as “a computer program that takes no input and produces a copy of its own source code as its only output”.  Some standard terms for this category of program are “self-replicating”, “self-reproducing”, and “self-copying” programs.  Quines are possible in any programming language.  The term quine, itself, was first coined in Douglas Hofstadter’s brilliant tome, “<em><a title="Gödel, Escher, Bach: An Eternal Golden Braid" href="http://en.wikipedia.org/wiki/G%C3%B6del,_Escher,_Bach:_An_Eternal_Golden_Braid">Gödel, Escher, Bach: An Eternal Golden Braid</a></em>, in the honor of philosopher <a title="Willard Van Orman Quine" href="http://en.wikipedia.org/wiki/Willard_Van_Orman_Quine">Willard Van Orman Quine</a> (1908–2000), who made an extensive study of <a title="Indirect self-reference" href="http://en.wikipedia.org/wiki/Indirect_self-reference">indirect self-reference</a>, and in particular for the paradox-producing expression, known as <a title="Quine's paradox" href="http://en.wikipedia.org/wiki/Quine%27s_paradox">Quine&#8217;s paradox</a>.</p>
<p>A while back, I was on an experimental jag centered on seeing just how badly I could abuse .NET  dynamic dispatch capabilities.  Specifically, what kind of DSLs could we make with C# dynamic and what would be the nature of a Quine built to accommodate fully adhoc call chaining over dynamics.  Well, this led to a series of DSLs and built on the metaprogramming concepts that fell out this work.  In this article, I will introduce you to the first and simplest DSL in this series, EchoDSL.  Echo is not a pure quine, yet it is a simple framework for creating self-replicating code.</p>
<p>Here is a test demonstrating the usage of the Echo:</p>

public void Testing_EchoDSL()

    Assert.AreEqual(self_is, should_be);

<p>As you can see we just kind of told Echo what it should repeat back to us, but the important thing is that we expressed that in source code.  The source is both legal C# and code that is obviously legal in the domain specific language itself.  To the point, in Echo, chained code that is syntactically legal in C#, it will happily convert to stringified source code and give back to you with a simple ToString() call.  The sheer meta”ness” of this may not be apparent on its face.  Let’s a try a more aggressive usage of Echo.</p>

<p>Again, we get a faithful representation from the code of itself as it executes.  There are a number of interesting points of note locked within this basic paradigm.  First, I am writing the code I want to write while writing it, and yet the program is executing and writing my code for me as well.  Second, given that it will accept any legal c# syntax, I can simply babble into the DSL and it will babble back.  And, beyond these superficial aspects, there are some potentially powerful genetic programming capabilities.  Consider, adding some semantic meanings and key words into the DSL that do more than just spool.   The output of a dynamic DSL such as Echo could be presented to CodeDom to produce and execute whole new programs that are runtime generated copies of itself, with perhaps mild nondeterministic mutations randomly interspersed.   What would millions of successive iterations produce?</p>
<p>Here is the implementation of EchoDSL: (this code uses the int.Times() extension method shown <a title="here" href="http://joelholder.com/2011/04/05/giving-your-data-some-functional-smarts-with-c/" target="_blank">here</a>)</p>
<pre class="brush: csharp; title: ; notranslate" title="">

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Dynamic;
using System.Xml.Linq;
using System.Text.RegularExpressions;

public class Echo : DynamicObject
{
    string history = &quot;&quot;;

    Dictionary&lt;string, Func&lt;Echo&gt;&gt; customOperators = new Dictionary&lt;string, Func&lt;Echo&gt;&gt;();

    /// &lt;summary&gt;
    /// Fluent Echo
    /// &lt;/summary&gt;
    /// &lt;param name=&quot;key&quot;&gt;&lt;/param&gt;
    /// &lt;returns&gt;&lt;/returns&gt;
    public Echo this&#x5B;string key]
    {
        get
        {
            RecordIndexerCall(key);
            if (customOperators.ContainsKey(key))
                return customOperators&#x5B;key]();
            else
                return Self();
        }
    }

    /// &lt;summary&gt;
    /// Fluent method getter for resolving self
    /// &lt;/summary&gt;
    private Func&lt;Echo&gt; Self
    {
        get { return () =&gt; this; }
    }

    /// &lt;summary&gt;
    /// Fluent Property used for spawning instances from static.
    /// &lt;/summary&gt;
    public static dynamic New
    {
        get
        {
            Func&lt;dynamic&gt; exp = () =&gt;
            {
                var b = new Echo();
                return (dynamic)b;
            };
            return exp.Invoke();
        }
    }

    public static dynamic _
    {
        get { return New; }
    }

    #region constructors and initialization

    protected void init()
    {
        customOperators.Add(&quot;self&quot;, () =&gt; Self());
        customOperators.Add(&quot;new&quot;, () =&gt; New);
        customOperators.Add(&quot;_&quot;, () =&gt; New);
    }

    public Echo()
    {
        //todo
        init();
    }

    public Echo(Echo Echo)
    {
        //todo
        init();
    }

    public Echo(Echo Echo1, Echo Echo2)
    {
        //todo
        init();
    }

    #endregion

    #region operator overloading

    public static Echo operator +(Echo c1, Echo c2)
    {
        c1.history += c2.history;
        return c1;
    }

    public static Echo operator -(Echo c1, Echo c2)
    {
        c2.history += c1.history;
        return c2;
    }

    #endregion

    #region overrides

    public override string ToString()
    {
        //echo output
        return history.ToString();
    }

    #endregion

    #region dynamic api

    public override bool TryGetMember(GetMemberBinder binder, out object result)
    {
        RecordPropertyCall(binder.Name);

        if (customOperators.ContainsKey(binder.Name))
            result = customOperators&#x5B;binder.Name]();
        else
            result = Self();
        return true;
    }

    public override bool TryInvokeMember(InvokeMemberBinder binder, object&#x5B;] args, out object result)
    {
        result = default(object);

        if (customOperators.ContainsKey(binder.Name))
            result = customOperators&#x5B;binder.Name]();
        else //build with it
        {

            var namedArgs = new Dictionary&lt;string, object&gt;();
            var indexArgs = new LinkedList&lt;object&gt;();
            Action prepare = () =&gt;
            {
                var diff = args.Count() - binder.CallInfo.ArgumentNames.Count;
                var argQueue = new Queue&lt;object&gt;(args);
                if (diff &gt; 0)
                {
                    diff.Times(i =&gt; indexArgs.AddLast(argQueue.Dequeue()));
                }

                var shiftedArgs = argQueue.ToArray();

                binder.CallInfo.ArgumentNames.Count().Times(i =&gt;
                {
                    namedArgs.Add(binder.CallInfo.ArgumentNames&#x5B;i], shiftedArgs&#x5B;i]);
                });
            };

            var work = new Func&lt;object&gt;(() =&gt;
                {
                    return null; //something
                });

            prepare();

            RecordMethodCall(binder.Name, indexArgs.ToArray(), namedArgs);

            //feed engine/managed state
            var output = work();
            //...

            result = Self();
        }

        return true;
    }

    #endregion

    #region private helpers
    void RecordMethodCall(string name, object&#x5B;] indexArgs, Dictionary&lt;string, object&gt; namedArgs)
    {
        //fix string args
        indexArgs.Count().Times(i =&gt; indexArgs&#x5B;i] = indexArgs&#x5B;i] is string ? &quot;\&quot;&quot; + indexArgs&#x5B;i] + &quot;\&quot;&quot; : indexArgs&#x5B;i]);
        var call = name + &quot;(&quot; + String.Join(&quot;, &quot;, indexArgs.ToArray());
        if (indexArgs.Count() &gt; 0)
            call += &quot;, &quot;;

        namedArgs.ToList().ForEach(namedArg =&gt;
            {
                call += namedArg.Key + &quot;: &quot;;
                call += (namedArg.Value is string ? &quot;\&quot;&quot; + namedArg.Value + &quot;\&quot;&quot; : &quot; &quot; + namedArg.Value) + &quot;, &quot;;
            });
        call = Regex.Replace(call.Trim(), &quot;,$&quot;, &quot;&quot;);
        call += &quot;)&quot;;
        history += &quot;.&quot; + call;
    }
    void RecordIndexerCall(string name)
    {
        var call = &quot;&#x5B;\&quot;&quot; + name + &quot;\&quot;]&quot;;
        history += call;
    }
    void RecordPropertyCall(string name)
    {
        var call = name;
        history += &quot;.&quot; + call;
    }
    #endregion
}
